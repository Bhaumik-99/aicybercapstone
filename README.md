**Coursework:** AI / Cybersecurity Capstone Lab

A reproducible academic prototype for detecting five illustrative network attack types using synthetic network-flow metadata. It compares Random Forest and MLP classifiers with an Isolation Forest anomaly detector, evaluates a simplified evasion experiment, produces feature explanations, and reports a time-group false-positive diagnostic.

> **Important:** The dataset is synthetic. Results are specific to this experiment and are not real-world detection claims. This is not a production security control and it does not inspect or block live network traffic.

## Project files

| File | Purpose |
|---|---|
| `threat_detection.py` | Complete runnable pipeline: synthetic data generation, models, evaluation, evasion test, explainability and plots |
| `requirements.txt` | Python dependencies |
| `design_report.md` | Design, threat model, methodology, evaluation and limitations |
| `outputs/results.json` | Metrics generated by the executed experiment |

## Threats modelled

- DDoS / traffic flooding
- Port scanning / reconnaissance
- Brute-force authentication attempts
- Suspected data exfiltration
- Command-and-control beaconing

## Run locally

Python 3.10+ is recommended.

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements.txt
python threat_detection.py
```

To also export the generated synthetic dataset:

```bash
python threat_detection.py --save-csv
```

The script creates `outputs/` and writes:
- `results.json`
- `confusion_matrix.png`
- `permutation_importance.png`
- `local_explanation.png`
- `adversarial_recall.png`
- `fpr_by_time_group.png`
- `synthetic_network_flows.csv` (only when `--save-csv` is supplied)

## Models and evaluation

- **Random Forest:** primary multi-class classifier.
- **MLP:** neural-network baseline with feature standardisation.
- **Isolation Forest:** unsupervised anomaly detector fitted only on normal training flows.

Evaluation includes accuracy, macro-F1, per-class precision/recall/F1, confusion matrix, binary attack precision/recall/F1, false-positive and false-negative counts, anomaly ROC-AUC, simulated evasion recall, permutation importance, a local feature-deviation view, and false-positive rates for working-hours/off-hours normal flows.

## Limitations and safe use

The flow records are generated from simplified distributions. The evasion experiment moves selected feature values toward the normal-training median; it does not represent every possible evasion method. The time-group diagnostic is not a fairness certification. Real deployment would require authorised telemetry, chronological validation, calibrated alert thresholds, drift monitoring, privacy review, analyst oversight and incident-response controls. The response guidance is advisory only.
